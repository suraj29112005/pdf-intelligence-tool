# PDF Intelligence Tool

A full-stack web application for reading, summarizing, searching, and chatting with PDF documents using AI, along with OCR support for scanned documents and image vision analysis.

## Features
- **PDF Upload & Management:** Upload PDFs with automatic text extraction, metadata parsing, and table extraction.
- **Scanned PDF Support:** Integrated Tesseract OCR and high-DPI rendering to read text from scanned or handwritten documents.
- **AI Document Chat & Summary:** Ask questions about your documents and get instant AI-powered summaries using Groq.
- **Image Vision Analysis:** Analyze embedded images, diagrams, and notes with custom questions, saving history securely.
- **Cloud Backup:** Automatic backup of PDFs to Cloudinary.
- **Authentication:** Secure user registration and login functionality.

## Tech Stack
- **Backend:** Python, FastAPI, SQLite, PyMuPDF, Pytesseract, Cloudinary, Groq/OpenAI API
- **Frontend:** React, Vite
